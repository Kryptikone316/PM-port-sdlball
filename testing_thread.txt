Game Information
Title: SDL-Ball
URL: https://github.com/DusteDdk/SDL-Ball

Instructions:
Ready to run. No additional setup required.

Known quirk: the very first launch after a fresh install (or after any update)
may crash right as you dismiss the title screen and start a level. Just
relaunch the port -- every relaunch after that first one is clean, this has
been 100% consistent across many repeated tests. Looks like a one-time cold
shader-cache compile race in the GL translation layer (gl4es), not something
in the game itself; only shows up once the on-screen-keyboard overlay
(libomni_osk.so) is loaded, never happens with it removed.
