## Notes

Thanks to [Jimmy Christensen](https://github.com/DusteDdk/SDL-Ball) for creating SDL-Ball, a DX-Ball/Breakout clone with genuinely pretty OpenGL particle effects and a between-level powerup shop that keeps runs feeling different each time.

## Controls

| Key | Action |
|--|--|
| Left Analog | Move Paddle / Navigate Menu |
| D-Pad Left/Right | Move Paddle |
| D-Pad Up | Shoot |
| A | Shoot / Confirm |
| B | Pause / Menu |
| X | Buy Powerup (shop) |
| L1 | Screenshot |
| Start | Pause / Menu |

## Compile

git clone --branch 1.04 https://github.com/DusteDdk/SDL-Ball.git
cd SDL-Ball
make
